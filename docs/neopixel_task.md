# Индивидуальная задача по проекту NeoPixel

## Тема задачи

Анализ кодовой логики управления осью Z фотополимерного 3D-принтера NeoPixel.

## Цель

Понять и описать, как программная часть проекта управляет движением платформы по оси Z с помощью ESP32-S3, драйвера A4988 и шагового двигателя NEMA17.

## Основание

В репозитории `Mini_Pixel_proj` уже есть файл `include/Stepmotor.h`, в котором описан класс `StepMotor`.

Этот класс отвечает за:

- настройку GPIO;
- включение и отключение драйвера двигателя;
- движение вверх и вниз;
- проверку концевого выключателя;
- калибровку нулевой позиции;
- выполнение последовательности движения для одного слоя.

## Что было сделано

Я выполнил анализ следующих частей:

| Элемент | Назначение |
| --- | --- |
| `app_main()` | Точка входа программы ESP-IDF |
| `StepMotor` | Класс управления шаговым двигателем |
| `begin()` | Настройка GPIO-пинов |
| `enable()` | Активация драйвера A4988 |
| `move()` | Генерация STEP-импульсов |
| `moveMM()` | Перевод миллиметров в шаги |
| `homing()` | Поиск нулевой позиции по концевику |
| `printLayerSequence()` | Последовательность движения для одного слоя |

## Почему эта задача важна

Ось Z является одной из ключевых частей фотополимерного принтера. Она отвечает за перемещение платформы, отрыв слоя от пленки и переход к следующему слою печати.

Если логика движения работает неправильно, принтер может:

- некорректно формировать слой;
- потерять нулевую позицию;
- повредить механику;
- неправильно выполнять калибровку.
