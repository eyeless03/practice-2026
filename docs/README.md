# Документация

В этой папке размещены Markdown-материалы по проектной практике.

## Состав папки

- `practice_documentation.md` - общее описание хода выполнения практики.
- `journal.md` - журнал этапов работы.
- `neopixel_task.md` - описание индивидуальной задачи по проекту NeoPixel.

Документация оформлена так, чтобы было понятно:

- какая тема выбрана для проектной деятельности;
- какая задача была выполнена в рамках NeoPixel;
- как задача связана с кодом проекта;
- какие материалы вынесены на статический сайт.

Основной сайт проекта находится в папке `site/`.
