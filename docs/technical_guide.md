# Техническое руководство: простой HTTP-сервер на Python

## Назначение

Вариативная часть практики посвящена созданию простого HTTP-сервера на Python. Проект выполнен как учебная реализация, чтобы показать, как сервер принимает запрос от браузера, разбирает его и формирует HTTP-ответ.

## Структура реализации

```text
src/
├── main.py
├── server.py
└── public/
    ├── index.html
    ├── about.html
    ├── 404.html
    └── style.css
```

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа. Разбирает аргументы командной строки и запускает сервер. |
| `server.py` | Основная логика HTTP-сервера: сокет, разбор запроса, маршруты, ответы и логирование. |
| `public/index.html` | Главная HTML-страница. |
| `public/about.html` | Страница с описанием проекта. |
| `public/404.html` | Страница ошибки для неизвестных путей. |
| `public/style.css` | Статический CSS-файл, отдаваемый через `/static/style.css`. |

## Как работает сервер

1. Пользователь запускает `python src/main.py`.
2. Программа создает объект `SimpleHTTPServer`.
3. Сервер открывает TCP-сокет и начинает слушать порт.
4. Браузер отправляет HTTP-запрос.
5. Сервер читает первую строку запроса.
6. По методу и пути выбирается нужный ответ.
7. Сервер отправляет HTTP-ответ и закрывает соединение.
8. В консоль выводится строка журнала.

## Маршрутизация

| Запрос | Результат |
| --- | --- |
| `GET /` | Возвращает `public/index.html`. |
| `GET /about` | Возвращает `public/about.html`. |
| `GET /static/style.css` | Возвращает статический CSS-файл. |
| `GET /unknown` | Возвращает `404 Not Found`. |
| `POST /` | Возвращает `405 Method Not Allowed`. |

## Запуск

```bash
python src/main.py
```

С указанием порта:

```bash
python src/main.py --host 127.0.0.1 --port 8080
```

После запуска сайт доступен по адресу:

```text
http://127.0.0.1:8080/
```

## Итог

В результате был реализован учебный HTTP-сервер без Flask, Django и других веб-фреймворков. Сервер показывает базовый цикл работы HTTP: принять запрос, разобрать путь, выбрать обработчик, сформировать ответ и вывести запись в журнал.
