# Документация по проектной практике

## Общая информация

Проектная практика выполняется на основе шаблона `mospol/practice-2025-1`.

Практика включает две смысловые части:

1. Статический сайт по проектной деятельности.
2. Вариативная часть по теме «Разработка простого HTTP-сервера на Python».

Первый сайт подготовлен по проекту **NeoPixel**. Проект связан с разработкой и доработкой малого фотополимерного 3D-принтера.

## Проект NeoPixel

NeoPixel - проект, в котором рассматриваются:

- конструкция фотополимерного 3D-принтера;
- аппаратная часть на ESP32-S3;
- управление шаговым двигателем оси Z;
- драйвер A4988;
- UV-матрица;
- дисплей;
- обслуживание и демонстрация оборудования.

## Моя задача в проектной деятельности

В рамках проектной деятельности я выбрал простую техническую задачу: разобрать кодовую логику управления осью Z.

Задача включала:

- изучение файла `include/Stepmotor.h` из репозитория `Mini_Pixel_proj`;
- анализ сигналов `STEP`, `DIR` и `EN`;
- объяснение роли драйвера A4988;
- описание работы функций `begin`, `enable`, `homing`, `move`, `moveMM` и `printLayerSequence`;
- подготовку блок-схемы кодовой логики;
- оформление результата на статическом сайте.

## Вариативная часть

Второй частью практики выбрана тема из `build-your-own-x`: **Python: A Simple Web Server**.

Для нее в структуре репозитория подготовлена папка `src/`. В ней размещено описание планируемой реализации:

- `src/README.md` - описание выбранной темы и планируемого результата.

Рабочие файлы для личного планирования и настройки агента не входят в репозиторий, так как они не относятся к обязательной структуре из методических материалов.
