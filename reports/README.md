# Отчетные материалы

В этой папке должны размещаться итоговые файлы отчета по проектной практике.

Ожидаемые файлы:

- `report.docx` или `Отчёт.docx`;
- `report.pdf` или `Отчёт.pdf`.

Структура отчета должна соответствовать шаблону из папки `task/`.

На текущем этапе подготовлены Markdown-материалы и статический сайт, которые можно использовать как основу для итогового отчета.
