## Тема проектной деятельности

Проектная деятельность связана с проектом **NeoPixel** - учебным проектом по разработке и доработке малого фотополимерного 3D-принтера.

В рамках сайта по проектной деятельности отражена моя задача: анализ кодовой логики управления осью Z, связанной с классом `StepMotor`, драйвером A4988, шаговым двигателем NEMA17 и концевым выключателем.

## Вариативная часть практики

В качестве вариативной части выбрана тема из репозитория `codecrafters-io/build-your-own-x`:

**Build your own Web Server / Python: A Simple Web Server**

Цель вариативной части - изучить принципы работы HTTP-сервера и реализовать учебный веб-сервер на Python. Материалы для этой части размещаются в папке `src/`.
