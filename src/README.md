# Исходный код

Эта папка предназначена для исходного кода вариативной части практики.

Выбранная тема вариативной части:

**Python: A Simple Web Server**

Источник темы: `codecrafters-io/build-your-own-x`, раздел `Build your own Web Server`.

Планируемый результат:

- простой HTTP-сервер на Python;
- обработка маршрутов `/` и `/about`;
- ответ `404 Not Found` для неизвестных путей;
- логирование запросов;
- техническое описание реализации в Markdown.

Код будет добавляться по мере выполнения вариативной части. На текущем этапе папка содержит описание выбранной темы и планируемого результата.
